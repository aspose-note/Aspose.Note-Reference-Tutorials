# Εξαγωγή όλου του κειμένου onenote και διαχείριση κειμένου OneNote

## Εισαγωγή

Εξάγετε όλο το κείμενο onenote με το Aspose.Note for Java και αποκτάτε αμέσως προγραμματισμένη πρόσβαση σε κάθε παράγραφο, κελί πίνακα και στοιχείο λίστας μέσα σε ένα αρχείο OneNote. Είτε δημιουργείτε ευρετήριο αναζήτησης, εξάγετε σημειώσεις σε άλλη μορφή, είτε δημιουργείτε προσαρμοσμένα πρότυπα, αυτή η δυνατότητα αποτελεί τη βάση κάθε προηγμένης αυτοματοποίησης OneNote. Σε αυτόν τον οδηγό καλύπτουμε επίσης πώς να δημιουργήσετε αρχεία προτύπων εγγράφων onenote και να δημιουργήσετε λιστές με κουκκίδες, ώστε να μπορείτε να χτίζετε ολοκληρωμένες λύσεις χωρίς χειροκίνητη αντιγραφή‑επικόλληση.

## Γρήγορες απαντήσεις
- **Τι σημαίνει “extract all text onenote”;** Σημαίνει την ανάκτηση κάθε κομματιού κειμενικού περιεχομένου από ένα αρχείο OneNote, ανεξαρτήτως της θέσης του σε μια σελίδα.  
- **Ποια βιβλιοθήκη το διαχειρίζεται;** Το Aspose.Note for Java παρέχει ένα ειδικό API για πλήρη εξαγωγή κειμένου.  
- **Χρειάζομαι άδεια;** Μια δωρεάν δοκιμή λειτουργεί για ανάπτυξη· απαιτείται εμπορική άδεια για παραγωγή.  
- **Μπορώ επίσης να δημιουργήσω λιστές με κουκκίδες;** Ναι—χρησιμοποιήστε το ίδιο API για να προσθέσετε δομές λίστας μετά την εξαγωγή κειμένου.  
- **Υποστηρίζεται η δημιουργία προτύπων;** Απόλυτα· η βιβλιοθήκη μπορεί να κλωνοποιήσει μια σελίδα και να αντικαταστήσει τα placeholders για να παραγάγει ένα πρότυπο εγγράφου onenote.

## Τι είναι η εξαγωγή όλου του κειμένου onenote;
Η εξαγωγή όλου του κειμένου onenote είναι η διαδικασία προγραμματισμένης ανάγνωσης κάθε κειμενικού στοιχείου από ένα έγγραφο OneNote. Το Aspose.Note διαβάζει τη εσωτερική δομή XML του OneNote και επιστρέφει μια συμβολοσειρά απλού κειμένου που διατηρεί την αρχική σειρά ανάγνωσης.

## Γιατί να χρησιμοποιήσετε το Aspose.Note for Java;
Το Aspose.Note υποστηρίζει **πάνω από 50 μορφές εισόδου και εξόδου**, μπορεί να διαχειριστεί σημειωματάρια με **εκατοντάδες σελίδες** χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη, και επεξεργάζεται τυπικές εργασίες εξαγωγής σε **κάτω από 200 ms ανά σελίδα** σε τυπικό εξοπλισμό διακομιστή. Αυτά τα ποσοτικοποιημένα οφέλη το καθιστούν αξιόπιστη επιλογή για μεγάλες επιχειρησιακές υλοποιήσεις.

- Java 17 ή νεότερη εγκατεστημένη στο μηχάνημα ανάπτυξης.

- Ένα έγκυρο αρχείο άδειας Aspose.Note for Java (ή χρήση της δοκιμαστικής λειτουργίας για δοκιμές).

## Πώς να εξάγετε όλο το κείμενο onenote;
Η κλάση `Notebook` αντιπροσωπεύει ένα σημειωματάριο OneNote και παρέχει πρόσβαση στις σελίδες του. Φορτώστε το αρχείο OneNote με το `Notebook` και καλέστε `getPages().extractText()`. Αυτή η κλήση μίας γραμμής επιστρέφει το πλήρες κειμενικό περιεχόμενο του σημειωματάριου, διατηρώντας τις αλλαγές παραγράφων, τα σύμβολα λίστας και τα περιεχόμενα κελιών πίνακα, ενώ διατηρεί την αρχική σειρά ανάγνωσης του εγγράφου.

## Πώς να δημιουργήσετε λίστα με κουκκίδες στο OneNote χρησιμοποιώντας το Aspose.Note for Java
`Page` αντιπροσωπεύει μια μεμονωμένη σελίδα μέσα σε ένα σημειωματάριο OneNote, και `Paragraph` δηλώνει ένα μπλοκ κειμένου σε αυτή τη σελίδα. Δημιουργήστε ένα αντικείμενο `Page`, δημιουργήστε ένα `Paragraph` με `ListStyleType.BULLET`, και προσθέστε το στη συλλογή περιεχομένου της σελίδας. Το API μορφοποιεί αυτόματα τα στοιχεία με σύμβολα κουκκίδας βάσει του επιλεγμένου στυλ, επιτρέποντάς σας να δημιουργήσετε ιεραρχικές λίστες με προσαρμοσμένη εσοχή και απόσταση.

## Πώς να δημιουργήσετε πρότυπο εγγράφου onenote
Δημιουργήστε μια σελίδα προτύπου που περιέχει tokens placeholder (π.χ., `{{Title}}`). Φορτώστε το πρότυπο, αντικαταστήστε κάθε token με πραγματικές τιμές χρησιμοποιώντας το `replaceText()`, και αποθηκεύστε το αποτέλεσμα ως νέο αρχείο OneNote. Η μέθοδος `replaceText()` αντικαθιστά κάθε εμφάνιση ενός token με τη δοθείσα συμβολοσειρά, επιτρέποντάς σας να παράγετε εξατομικευμένα πρακτικά συναντήσεων, αναφορές ή συμβάσεις σε κλίμακα χωρίς χειροκίνητη επεξεργασία.

## Πώς να προσθέσετε σκοτεινό θέμα στο κείμενο OneNote
`TextStyle` ορίζει χαρακτηριστικά μορφοποίησης όπως γραμματοσειρά, χρώμα και φόντο για στοιχεία κειμένου. Εφαρμόστε ένα `TextStyle` με σκούρο χρώμα φόντου και ανοιχτό χρώμα προσκηνίου στα επιθυμητά αντικείμενα `Paragraph`. Η βιβλιοθήκη ενημερώνει το υποκείμενο XML του OneNote, ώστε το θέμα να παραμένει όταν το αρχείο ανοίγει στον πελάτη OneNote, δίνοντας στις σημειώσεις σας μια σύγχρονη, υψηλής αντίθεσης εμφάνιση.

## Πώς να ανακτήσετε ιδιότητες λίστας από μια σελίδα OneNote
`List` αντιπροσωπεύει μια δομή λίστας συνδεδεμένη με μια παράγραφο, αποθηκεύοντας το στυλ και τις πληροφορίες ιεραρχίας της. Χρησιμοποιήστε το αντικείμενο `List` που σχετίζεται με μια παράγραφο για να διαβάσετε το `listId`, `listLevel` και `listStyle`. Αυτές οι ιδιότητες σας επιτρέπουν να ελέγχετε προγραμματισμένα ή να τροποποιείτε υπάρχουσες δομές λίστας, όπως η αλλαγή τύπων κουκκίδων ή η προσαρμογή επιπέδων ένθεσης, ώστε να ταιριάζουν στις απαιτήσεις μορφοποίησης του εγγράφου σας.

## Πώς να αντικαταστήσετε κείμενο σε συγκεκριμένες σελίδες
Στοχεύστε μια συγκεκριμένη `Page` με το ID της, καλέστε `replaceText(oldValue, newValue)`, και αποθηκεύστε το σημειωματάριο. Η μέθοδος `replaceText()` αναζητά μόνο εντός της επιλεγμένης σελίδας, εξασφαλίζοντας ότι μόνο το επιθυμητό περιεχόμενο τροποποιείται ενώ το υπόλοιπο του εγγράφου παραμένει αμετάβλητο, κάτι που είναι ουσιώδες για ακριβείς ενημερώσεις σε επίπεδο σελίδας.

## Πώς να αντικαταστήσετε κείμενο σε όλες τις σελίδες
Επανάληψη μέσω `Notebook.getPages()` και κλήση του `replaceText()` σε κάθε σελίδα. Αυτή η μαζική λειτουργία είναι αποδοτική επειδή η βιβλιοθήκη επεξεργάζεται τις σελίδες διαδοχικά χωρίς να φορτώνει ολόκληρο το σημειωματάριο στη μνήμη, επιτρέποντάς σας να ενημερώσετε μεγάλα σημειωματάρια γρήγορα ενώ διατηρείτε τη χρήση μνήμης χαμηλή.
