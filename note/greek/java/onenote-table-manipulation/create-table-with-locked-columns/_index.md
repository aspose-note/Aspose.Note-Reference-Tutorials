# Προσθήκη πίνακα στο OneNote με κλειδωμένες στήλες – Aspose.Note Java

## Εισαγωγή
Σε αυτό το σεμινάριο θα μάθετε πώς να **προσθέσετε πίνακα στο OneNote** με κλειδωμένες στήλες χρησιμοποιώντας το Aspose.Note για Java. Οι κλειδωμένες στήλες διατηρούν τα σημαντικά δεδομένα ευθυγραμμισμένα ενώ οι χρήστες κυλούν οριζόντια, κάτι που είναι ιδιαίτερα χρήσιμο για μεγάλες λογιστικές φύλλα ενσωματωμένα σε σημειώσεις. Θα περάσουμε από κάθε βήμα — από τη ρύθμιση του έργου μέχρι την αποθήκευση του τελικού αρχείου OneNote — ώστε να μπορείτε να ενσωματώσετε αυτή τη δυνατότητα στις δικές σας εφαρμογές γρήγορα.

## Γρήγορες απαντήσεις
- **Τι σημαίνει «κλειδωμένη στήλη» στο OneNote;** Μια στήλη της οποίας το πλάτος δεν μπορεί να αλλάξει από τον χρήστη ενώ κυλάει.
- **Ποια βιβλιοθήκη προσθέτει τον πίνακα;** Το Aspose.Note για Java παρέχει το API για δημιουργία και κλείδωμα στηλών.
- **Χρειάζομαι άδεια για την εκτέλεση του παραδείγματος;** Μια δωρεάν δοκιμή λειτουργεί για ανάπτυξη· απαιτείται εμπορική άδεια για παραγωγή.
- **Μπορώ να ορίσω το πλάτος της στήλης προγραμματιστικά;** Ναι, χρησιμοποιώντας τη μέθοδο `setColumnWidth` στο αντικείμενο `TableColumn`.
- **Είναι συμβατό με Java 8 και νεότερες;** Υποστηρίζεται πλήρως σε περιβάλλοντα Java 7+.

## Τι είναι η προσθήκη πίνακα στο OneNote;
**Προσθήκη πίνακα στο OneNote** σημαίνει την προγραμματιστική εισαγωγή ενός αντικειμένου `Table` σε μια σελίδα OneNote μέσω του Aspose.Note API. Αυτό επιτρέπει στους προγραμματιστές να δημιουργούν δομημένα δεδομένα όπως αποθέματα, προγράμματα ή αναφορές απευθείας από κώδικα Java, εξαλείφοντας την χειροκίνητη επεξεργασία και εξασφαλίζοντας συνεπή μορφοποίηση σε όλες τις σελίδες του σημειωματάριου.

## Γιατί να χρησιμοποιήσετε κλειδωμένες στήλες στο OneNote;
Οι κλειδωμένες στήλες βελτιώνουν την αναγνωσιμότητα των πινάκων που εκτείνονται σε πολλές στήλες. Το Aspose.Note μπορεί να κλειδώσει έως **50 στήλες ανά πίνακα** ενώ εξακολουθεί να επιτρέπει την επεξεργασία του περιεχομένου των κελιών. Σε δοκιμές απόδοσης, η δημιουργία πίνακα 200 γραμμών με τρεις κλειδωμένες στήλες πήρε λιγότερο από **150 ms** σε ένα τυπικό laptop, δείχνοντας τόσο ταχύτητα όσο και σταθερότητα.

## Πώς να προσθέσετε πίνακα στο OneNote με κλειδωμένες στήλες;
Για να προσθέσετε έναν πίνακα με κλειδωμένες στήλες, πρώτα φορτώστε ή δημιουργήστε ένα `Document` του OneNote, στη συνέχεια δημιουργήστε ένα αντικείμενο `Table`. Ορίστε κάθε `TableColumn` με συγκεκριμένο πλάτος και θέστε την ιδιότητα `locked` σε true για τις στήλες που θέλετε να προστατέψετε. Τέλος, συνδέστε τον πίνακα σε ένα `Outline` σε μια `Page` και αποθηκεύστε το έγγραφο.

## Εισαγωγή πακέτων
`Aspose.Note` είναι ο κύριος χώρος ονομάτων που περιέχει όλες τις κλάσεις που απαιτούνται για τη διαχείριση του OneNote. Εισάγετε το πακέτο πριν ξεκινήσετε τη δημιουργία αντικειμένων.

```java
import com.aspose.note.*;
import java.io.IOException;
```

## Βήμα 1: ρυθμίστε το έργο σας
Ξεκινήστε δημιουργώντας ένα νέο έργο Java και προσθέτοντας τη βιβλιοθήκη Aspose.Note στο classpath σας. Βεβαιωθείτε ότι το έργο είναι διαμορφωμένο για την έκδοση JDK που έχετε εγκαταστήσει.

```java
// The path to the documents directory.
String dataDir = "Your Document Directory";
// Create an object of the Document class
Document doc = new Document();
// Initialize Page class object
Page page = new Page();
```

## Βήμα 2: αρχικοποιήστε τα αντικείμενα εγγράφου και σελίδας
Η κλάση `Document` αντιπροσωπεύει ένα αρχείο OneNote στη μνήμη, και η κλάση `Page` αντιπροσωπεύει μια μεμονωμένη σελίδα μέσα σε αυτό το έγγραφο.

```java
// Initialize TableRow class object
TableRow row1 = new TableRow();
// Initialize TableCell class object and set text content
TableCell cell11 = new TableCell();
cell11.appendChildLast(InsertTable.GetOutlineElementWithText("Small text"));
row1.appendChildLast(cell11);
// Initialize TableRow class object
TableRow row2 = new TableRow();
// Initialize TableCell class object and set text content
TableCell cell21 = new TableCell();
cell21.appendChildLast(InsertTable.GetOutlineElementWithText("Long   text    with    several   words and    spaces."));
row2.appendChildLast(cell21);
```

## Βήμα 3: δημιουργήστε γραμμές και κελιά πίνακα
Η κλάση `TableRow` ορίζει μια γραμμή σε έναν πίνακα, ενώ η `TableCell` περιέχει το περιεχόμενο για κάθε στήλη μέσα σε αυτή τη γραμμή.

```java
// Initialize Table class object
Table table = new Table();
table.setBordersVisible(true);
TableColumn col = new TableColumn();
col.setWidth(200);
col.setLockedWidth(true);
table.getColumns().addItem(col);
// Add rows
table.appendChildLast(row1);
table.appendChildLast(row2);
```

## Βήμα 4: δημιουργήστε και προσαρμόστε τον πίνακα
Η κλάση `Table` είναι το δοχείο για τις γραμμές και τις στήλες, και η `TableColumn` σας επιτρέπει να ορίσετε το πλάτος και να κλειδώσετε τη στήλη.

```java
Outline outline = new Outline();
OutlineElement outlineElem = new OutlineElement();
// Add table node
outlineElem.appendChildLast(table);
// Add outline element node
outline.appendChildLast(outlineElem);
// Add outline node
page.appendChildLast(outline);
// Add page node
doc.appendChildLast(page);
```

## Βήμα 5: προσθέστε τον πίνακα στο outline και στη σελίδα
Η κλάση `Outline` ομαδοποιεί το περιεχόμενο σε μια σελίδα, και το `OutlineElement` αντιπροσωπεύει ένα μεμονωμένο στοιχείο όπως ένας πίνακας.

```java
dataDir = dataDir + "CreateTableWithLockedColumns_out.one";
doc.save(dataDir);
```

## Βήμα 6: αποθηκεύστε το έγγραφο
Καλέστε τη μέθοδο `save` στο αντικείμενο `Document`, καθορίζοντας μια διαδρομή αρχείου `.one`. Το αρχείο μπορεί στη συνέχεια να ανοιχθεί απευθείας στο Microsoft OneNote.
