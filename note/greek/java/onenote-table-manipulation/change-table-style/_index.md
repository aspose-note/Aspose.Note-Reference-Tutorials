## Πώς να ορίσετε χρώμα φόντου γραμμής σε πίνακες OneNote;
Φορτώστε το αρχείο OneNote, εντοπίστε κάθε κόμβο `Table` και καλέστε `setRowStyle` για κάθε `Row`. Η μέθοδος `setRowStyle` αναθέτει μια τιμή `BackgroundColor`, την οποία το API γράφει πίσω στο αρχείο όταν αποθηκεύετε. Αυτή η προσέγγιση λειτουργεί για πίνακες οποιουδήποτε μεγέθους και διατηρεί το υπάρχον περιεχόμενο όπως κείμενο και εικόνες.

### Βήμα 1: ρύθμιση του εγγράφου
Η κλάση `Document` αντιπροσωπεύει ένα αρχείο OneNote και παρέχει πρόσβαση στις σελίδες, ενότητες και περιεχόμενό του.  
Φορτώστε το έγγραφο OneNote στο Aspose.Note και ανακτήστε τη λίστα των κόμβων πίνακα.  
```java
// Set up the document and get the list of table nodes
String dataDir = "Your Document Directory";
Document document = new Document(dataDir + "ChangeTableStyleIn.one");
List<Table> nodes = document.getChildNodes(Table.class);
```

### Βήμα 2: ορισμός στυλ γραμμών
Διασχίστε κάθε πίνακα, ορίζοντας το στυλ για κάθε γραμμή, συμπεριλαμβανομένης της επισήμανσης της πρώτης γραμμής μετά την κεφαλίδα. Η πρώτη γραμμή είναι συχνά κεφαλίδα, οπότε μπορεί να θέλετε μια πιο σκούρα απόχρωση για αντίθεση.  
```java
// Set row styles for each table in the document
for (Table table : nodes) {
    setRowStyle(table.getFirstChild(), Color.GRAY, true, true);
    // Highlight first row after the head.
    boolean flag = false;
    List<TableRow> rows = table.getChildNodes(TableRow.class);
    for (int i = 1; i < rows.size(); ++i) {
        setRowStyle(rows.get(i), flag ? Color.lightGray : new java.awt.Color(-1, true), false, false);
        flag = !flag;
    }
}
```

### μέθοδος setRowStyle
Η μέθοδος `setRowStyle` λαμβάνει ένα αντικείμενο `Row` και μια τιμή `Color`, και στη συνέχεια ενημερώνει το φόντο της γραμμής.  
```java
    private static void setRowStyle(TableRow row, Color highlightColor, boolean bold, boolean italic) {
        for (TableCell cell: row)
        {
            cell.setBackgroundColor(highlightColor);
            for (RichText node: cell.getChildNodes(RichText.class))
            {
                node.getParagraphStyle().setBold(bold);
                node.getParagraphStyle().setItalic(italic);
                for (TextRun run: node.getTextRuns())
                {
                    run.getStyle().setBold(bold);
                    run.getStyle().setItalic(italic);
                }
            }
        }
    }
```

### Βήμα 3: αποθήκευση του εγγράφου
Αποθηκεύστε το τροποποιημένο έγγραφο με τα νέα στυλ πίνακα. Το API γράφει τις αλλαγές χωρίς να τροποποιεί άλλα μέρη του σημειωματάριου.  
```java
// Save the modified document
document.save(Paths.get(dataDir, "ChangeTableStyleOut.one").toString());
```
