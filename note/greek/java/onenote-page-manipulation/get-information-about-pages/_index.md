## Βήμα 1: Φόρτωση του εγγράφου OneNote

`Document` είναι η κύρια κλάση του Aspose.Note που αντιπροσωπεύει ένα σημειωματάριο OneNote φορτωμένο στη μνήμη, παρέχοντας πρόσβαση στις ενότητες και τις σελίδες του.

Φορτώστε το αρχείο OneNote σας σε ένα αντικείμενο `Aspose.Note` `Document`.

```java
String dataDir = "Your Document Directory";
// Load the document into Aspose.Note
LoadOptions options = new LoadOptions();
Document doc = new Document(dataDir + "Sample1.one", options);
```

## Πώς να ανακτήσετε τα aspose note page details προγραμματιστικά;

Φορτώστε το έγγραφο, στη συνέχεια επαναλάβετε τη συλλογή των σελίδων του. **`Page` αντιπροσωπεύει μια μεμονωμένη σελίδα μέσα σε ένα έγγραφο OneNote, περιέχοντας το περιεχόμενό της και τα μεταδεδομένα.** Για κάθε αντικείμενο `Page` μπορείτε να διαβάσετε `getLastModifiedTime()`, `getCreationTime()`, `getTitle()`, `getLevel()` και `getAuthor()`. Αυτός ο απλός βρόχος επιστρέφει όλα τα aspose note page details που χρειάζεστε σε λίγες μόνο γραμμές κώδικα.

## Βήμα 2: Ανάκτηση Πληροφοριών Σελίδας

Τώρα θα **εξάγουμε το last modified time** μαζί με άλλα χρήσιμα μεταδεδομένα.

```java
// Get page revisions
List<Page> pages = doc.getChildNodes(Page.class);

// Traverse list of pages
for (Page pageRevision : pages) {
    System.out.println("LastModifiedTime: " + pageRevision.getLastModifiedTime());
    System.out.println("CreationTime: " + pageRevision.getCreationTime());
    System.out.println("Title: " + pageRevision.getTitle());
    System.out.println("Level: " + pageRevision.getLevel());
    System.out.println("Author: " + pageRevision.getAuthor());
}
```

Ο βρόχος εκτυπώνει το **last modified time**, την ημερομηνία δημιουργίας, τον τίτλο, το ιεραρχικό επίπεδο και τον συγγραφέα κάθε σελίδας στην κονσόλα.

## Συνηθισμένα Πιθανά Σφάλματα & Συμβουλές

- **Null values** – Ορισμένες σελίδες μπορεί να μην έχουν ορισμένο συγγραφέα· προστατέψτε τον κώδικά σας από `null` κατά την επεξεργασία.  
- **Time zones** – `getLastModifiedTime()` επιστρέφει ένα `java.util.Date` στη προεπιλεγμένη ζώνη ώρας του συστήματος. Μετατρέψτε σε UTC εάν χρειάζεστε καθολική αναφορά.  
- **Large notebooks** – Για σημειωματάρια με εκατοντάδες σελίδες, σκεφτείτε την επεξεργασία σε παρτίδες για να μειώσετε την κατανάλωση μνήμης.
