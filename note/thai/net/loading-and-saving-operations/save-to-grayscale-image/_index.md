# วิธีแปลง OneNote เป็น PNG และบันทึกเป็นภาพระดับสีเทา

## บทนำ

ในบทเรียนนี้คุณจะได้เรียนรู้ **วิธีแปลง OneNote เป็น PNG** และบันทึกผลลัพธ์เป็นภาพระดับสีเทาโดยใช้ Aspose.Note สำหรับ .NET การแปลงหน้า OneNote เป็น PNG เป็นความต้องการทั่วไปสำหรับการรายงาน การสร้างภาพย่อ และกระบวนการเก็บถาวร Aspose.Note ทำให้กระบวนการง่ายขึ้น โดยให้คุณจัดการไฟล์โดยไม่ต้องติดตั้ง Microsoft OneNote

## คำตอบอย่างรวดเร็ว
- **ไลบรารีที่จัดการการแปลงคืออะไร?** Aspose.Note for .NET.
- **รูปแบบที่สร้างคืออะไร?** PNG grayscale image.
- **ต้องใช้บรรทัดของโค้ดกี่บรรทัด?** Four core statements (load, set options, save, verify).
- **ต้องใช้ไลเซนส์สำหรับการผลิตหรือไม่?** Yes, a commercial license is needed; a free trial is available.
- **สามารถรันบน .NET 6+ ได้หรือไม่?** Absolutely – Aspose.Note supports .NET Framework 4.5+, .NET Core 3.1+, and .NET 6+.

## การแปลง OneNote เป็น PNG คืออะไร?
`convert OneNote to PNG` คือกระบวนการเรนเดอร์หน้าของ OneNote ให้เป็นภาพ Portable Network Graphics (PNG) bitmap โดยอาจทำการแปลงสีเช่นระดับสีเทา รูปแบบนี้รักษาความคมชัดของภาพขณะให้ไฟล์มีขนาดเบาและเป็นมิตรต่อเว็บ มักใช้สำหรับฝังภาพสแนปช็อตของเอกสารในหน้าเว็บ การสร้างภาพย่อ หรือการเก็บถาวรเนื้อหาในรูปแบบที่ไม่พึ่งพาซอฟต์แวร์ที่เป็นกรรมสิทธิ์

## ทำไมต้องใช้ Aspose.Note สำหรับการแปลงนี้?
Aspose.Note รองรับ **รูปแบบอินพุตและเอาต์พุตกว่า 50+** และสามารถเรนเดอร์โน้ตบุ๊ก OneNote หลายหน้าโดยไม่ต้องโหลดไฟล์ทั้งหมดเข้าสู่หน่วยความจำ ทำให้สามารถแปลงเอกสารขนาดถึง **500 MB** ได้ภายในเวลาไม่เกิน **2 วินาที** บนฮาร์ดแวร์เซิร์ฟเวอร์ทั่วไป ไลบรารียังมีการเรนเดอร์ระดับสีเทาในตัว ลดความจำเป็นในการใช้เครื่องมือประมวลผลภาพของบุคคลที่สาม

- คุ้นเคยกับการเข้าถึงและจัดการไฟล์ด้วย .NET.

## ฉันจะแปลง OneNote เป็น PNG และบันทึกเป็นภาพระดับสีเทาอย่างไร?
โหลดเอกสาร OneNote กำหนดค่าตัวเลือกการบันทึกภาพเพื่อเปิดใช้งานระดับสีเทา บันทึกผลลัพธ์เป็นไฟล์ PNG และสุดท้ายตรวจสอบว่าไฟล์มีอยู่บนดิสก์ กระบวนการทั้งหมดครอบคลุมในสี่ขั้นตอนด้านล่าง แต่ละขั้นตอนมีตัวอย่างโค้ดสั้น ๆ ที่สามารถนำไปใช้ในแอปพลิเคชันของคุณได้โดยตรง

### นำเข้าเนมสเปซ

Let's start by importing the necessary namespaces:

```csharp
using System;

using Aspose.Note.Saving;

```

### ขั้นตอนที่ 1: โหลดเอกสาร

ก่อนอื่น โหลดเอกสารเข้าสู่ Aspose.Note.  
คลาส `Document` แทนโน้ตบุ๊ก OneNote และให้เมธอดสำหรับโหลดและจัดการเนื้อหา

```csharp
string dataDir = "Your Document Directory";
Document oneFile = new Document(dataDir + "Aspose.one");
```

### ขั้นตอนที่ 2: บันทึกเป็นภาพระดับสีเทา

ต่อไป ระบุเส้นทางสำหรับบันทึกภาพระดับสีเทาและบันทึกเอกสารตามนั้น.  
คลาส `ImageSaveOptions` ให้คุณกำหนดรูปแบบภาพและตัวเลือกการเรนเดอร์เช่นโหมดสี

```csharp
dataDir = dataDir + "SaveAsGrayscaleImage_out.png";
oneFile.Save(dataDir, new ImageSaveOptions(SaveFormat.Png)
					  {
						  ColorMode = ColorMode.GrayScale
					  });
```

### ขั้นตอนที่ 3: ตรวจสอบและแสดงผล

สุดท้าย ตรวจสอบและแสดงข้อความการแปลงสำเร็จพร้อมเส้นทางไฟล์

```csharp
Console.WriteLine("\nOneNote document converted successfully to grayscale image.\nFile saved at " + dataDir);
```

## ปัญหาทั่วไปและวิธีแก้
- **ไม่พบไฟล์หลังการบันทึก** – ตรวจสอบให้แน่ใจว่าไดเรกทอรีผลลัพธ์มีอยู่และแอปพลิเคชันมีสิทธิ์เขียน.
- **ภาพแสดงเป็นสี** – ตรวจสอบว่า `ImageSaveOptions` มี `ColorMode` ตั้งเป็น `Grayscale`.
- **โน้ตบุ๊กขนาดใหญ่ทำให้ใช้หน่วยความจำสูง** – ใช้ `LoadOptions` กับ `LoadOptions.LoadMode = LoadMode.Stream` เพื่อประมวลผลหน้าแบบต่อเนื่อง.
