# Splitting 알고리즘을 사용한 onenote PDF 내보내기 Aspose.Note

## 소개

프로그램matically **export onenote to pdf** 해야 한다면, Aspose.Note for Java가 이를 간단하게 만들어 줍니다. 이 튜토리얼에서는 Splitting Algorithm 방법을 살펴보며, 페이지마다 콘텐츠가 어떻게 나뉘는지 제어하여 깔끔하고 읽기 쉬운 PDF 출력을 보장합니다. PDF 저장 옵션을 설정하고, 적절한 페이지‑분할 알고리즘을 선택한 뒤, 몇 줄의 Java 코드만으로 PDF 파일을 생성하는 과정을 확인할 수 있습니다.

## 빠른 답변

- **Splitting Algorithm은 무엇을 하나요?** 페이지 경계를 넘는 객체가 OneNote 페이지를 PDF로 내보낼 때 어떻게 처리되는지를 결정합니다.  
- **필요한 라이브러리는 무엇인가요?** Aspose.Note for Java (공식 Aspose 사이트에서 다운로드).  
- **라이선스가 필요합니까?** 프로덕션 사용을 위해 임시 또는 정식 라이선스가 필요하며, 무료 체험판을 이용할 수 있습니다.  
- **대용량 OneNote 노트북을 내보낼 수 있나요?** 예 — 라이브러리는 수천 페이지에 이르는 노트북을 효율적으로 처리하고 페이지‑분할 규칙을 설정할 수 있습니다.  
- **지원되는 출력 형식은 무엇인가요?** PDF, JPEG, PNG, XPS 등이며, 이 가이드는 PDF 내보내기에 중점을 둡니다.  
- **PDF 이미지 압축은 어떻게 하나요?** 생성된 PDF의 이미지 크기를 줄이려면 `pdfSaveOptions.setCompressImages(true)`를 사용합니다.  

## export onenote to pdf란 무엇인가요?

Exporting onenote to pdf는 기본 `.one` 파일 형식을 휴대용 PDF 문서로 변환하는 것을 의미합니다. 이 변환은 원래 레이아웃, 텍스트 서식 및 포함된 객체를 보존하여 OneNote 애플리케이션 없이도 콘텐츠를 쉽게 공유, 보관 또는 인쇄할 수 있게 합니다. 생성된 PDF는 PDF 뷰어를 지원하는 모든 장치에서 열 수 있습니다.

## export onenote to pdf에 Splitting Algorithm을 사용하는 이유는?

Splitting algorithm은 표, 이미지, 도면과 같은 복잡한 객체가 페이지 구분 시 어떻게 처리되는지 세밀하게 제어할 수 있게 해줍니다. 적절한 알고리즘을 선택하면 시각적 레이아웃을 유지하고, 잘려 나간 콘텐츠를 방지하며, 생성되는 페이지 수를 줄일 수 있습니다. 이는 특히 다양한 미디어 요소가 많은 대용량 노트북에서 더 깔끔한 PDF, 향상된 가독성 및 효율적인 저장을 가능하게 합니다.

* 각 페이지의 시각적 레이아웃을 보존합니다.  
* 잘려 나갈 수 있는 콘텐츠를 방지합니다.  
* 객체를 다음 페이지로 깔끔하게 이동시켜 생성되는 페이지 수를 줄입니다.  

## .one 파일을 pdf로 변환하는 방법은?

`.one` 파일을 PDF로 변환하려면 먼저 원본 OneNote 문서를 메모리로 로드한 다음, 원하는 Splitting Algorithm 및 이미지 압축과 같은 추가 설정을 포함해 `PdfSaveOptions`를 구성합니다. 마지막으로 `Document` 객체의 `save` 메서드를 호출하여 출력 PDF 경로를 지정합니다. 이 3단계 패턴은 크기에 관계없이 노트북에 적용되며, 페이지 구분 처리를 결정적으로 보장합니다.

## 패키지 가져오기

Java 프로젝트에서 Aspose.Note 기능을 사용하기 위해 필요한 패키지를 가져옵니다.

```java
import java.io.IOException;
import com.aspose.note.AlwaysSplitObjectsAlgorithm;
import com.aspose.note.Document;
import com.aspose.note.KeepPartAndCloneSolidObjectToNextPageAlgorithm;
import com.aspose.note.KeepSolidObjectsAlgorithm;
import com.aspose.note.PdfSaveOptions;
```

## Step 1: 문서 디렉터리 정의

OneNote 문서가 위치한 디렉터리를 설정합니다.

```java
String dataDir = "Your Document Directory";
```

## Step 2: OneNote 문서 로드

`Document` 클래스는 메모리 내에서 OneNote 노트북을 나타내며, 페이지를 읽고, 수정하고, 저장할 수 있게 해줍니다.

```java
Document doc = new Document(dataDir + "Sample1.one");
```

## Step 3: PDF 저장 옵션 설정

`PdfSaveOptions` 클래스는 페이지 분할, 이미지 압축, 준수 수준 등 PDF 내보내기 설정을 정의합니다.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
```

## Step 4: 페이지 분할 알고리즘 설정

`KeepPartAndCloneSolidObjectToNextPageAlgorithm` 알고리즘은 객체의 일부를 현재 페이지에 유지하고 나머지를 다음 페이지에 복제하여 레이아웃을 보존합니다.

```java
pdfSaveOptions.setPageSplittingAlgorithm(new KeepPartAndCloneSolidObjectToNextPageAlgorithm(100));
```

## Step 5: 문서 저장

지정된 PDF 저장 옵션으로 문서를 저장합니다. 이 단계는 **PDF onenote** 출력을 생성하며, 이를 열거나, 공유하거나, 인쇄할 수 있습니다.

```java
try {
    doc.save(dataDir + "UsingSplittingAlgorithmMethod_out.Jpeg", pdfSaveOptions);
} catch (Exception ex) {
    System.out.println("Exception: " + ex.getMessage());
}
```

## 일반적인 문제 및 해결책

| 문제 | 해결책 |
|-------|----------|
| **페이지 경계에서 객체가 잘림** | `AlwaysSplitObjectsAlgorithm`와 같은 다른 알고리즘을 시도하거나 `KeepPartAndCloneSolidObjectToNextPageAlgorithm`의 임계값을 늘려보세요. |
| **출력 PDF가 비어 있음** | 소스 `.one` 파일이 손상되지 않았는지 및 `dataDir` 경로가 올바른지 확인하십시오. |
| **대용량 노트북에서 성능이 느림** | `pdfSaveOptions.setCompressImages(true)`를 사용하여 메모리 사용량을 줄이고, 노트북을 더 작은 섹션으로 처리하는 것을 고려하십시오. Aspose.Note는 최대 10 000 페이지의 노트북을 처리할 수 있으며, 일반 서버에서 500 페이지 노트북을 5초 미만에 처리합니다. |
