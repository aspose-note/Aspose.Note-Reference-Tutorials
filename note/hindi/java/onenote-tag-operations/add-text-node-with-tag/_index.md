# Aspose.Note का उपयोग करके टेक्स्ट नोड जोड़कर OneNote दस्तावेज़ में टैग कैसे जोड़ें

## परिचय
इस ट्यूटोरियल में आप **टैग कैसे जोड़ें** यह सीखेंगे, Aspose.Note Java API का उपयोग करके OneNote दस्तावेज़ में। हम एक नया OneNote फ़ाइल बनाना, पैराग्राफ को स्टाइल करना, टेक्स्ट पर बिल्ट‑इन टैग संलग्न करना, और अंत में एक ही `save` कॉल से नोटबुक को सहेजना दिखाएंगे। चाहे आप व्यक्तिगत नोट‑लेने के यूटिलिटी बना रहे हों या एंटरप्राइज़ रिपोर्टिंग को ऑटोमेट कर रहे हों, नीचे दिए गए चरण आपको OneNote सामग्री पर पूर्ण प्रोग्रामेटिक नियंत्रण प्रदान करेंगे।

## त्वरित उत्तर
- **Aspose.Note क्या करता है?** यह एक Java API प्रदान करता है जिससे आप Microsoft Office स्थापित किए बिना OneNote फ़ाइलों को पढ़, संशोधित और बना सकते हैं।  
- **टैग वाले टेक्स्ट नोड को जोड़ने के लिए कितनी पंक्तियों का कोड चाहिए?** लगभग 15 पंक्तियाँ, जिसमें ऑब्जेक्ट निर्माण और स्टाइलिंग शामिल है।  
- **क्या नमूना चलाने के लिए लाइसेंस आवश्यक है?** विकास के लिए एक फ्री ट्रायल काम करता है; उत्पादन उपयोग के लिए लाइसेंस आवश्यक है।  
- **क्या मैं टैग आइकन बदल सकता हूँ?** हाँ – Aspose.Note 30 से अधिक बिल्ट‑इन आइकन प्रदान करता है जैसे पीला सितारा, चेकमार्क, और हार्ट।  
- **आउटपुट फ़ाइल का फ़ॉर्मेट क्या है?** लाइब्रेरी परिणाम को एक मानक *.one* OneNote फ़ाइल के रूप में सहेजती है।

## “OneNote दस्तावेज़ बनाना” का क्या अर्थ है?
OneNote दस्तावेज़ बनाना मतलब प्रोग्रामेटिक रूप से एक *.one* फ़ाइल उत्पन्न करना है जिसे Microsoft OneNote में खोला जा सकता है। इस फ़ाइल में पेज, आउटलाइन, और रिच‑टेक्स्ट तत्व होते हैं जो Aspose.Note API के माध्यम से निर्मित होते हैं, जिससे आप डेस्कटॉप एप्लिकेशन या अन्य टूल्स के बिना नोटबुक बना सकते हैं।

## टैग के साथ टेक्स्ट नोड क्यों जोड़ें?
टैग वाले टेक्स्ट नोड को जोड़ने से महत्वपूर्ण जानकारी उजागर होती है और OneNote की बिल्ट‑इन टैग नेविगेशन सक्षम होती है, जो रिव्यू और टास्क मैनेजमेंट को तेज़ बनाती है। टैग मेटाडेटा के रूप में संग्रहीत होते हैं, इसलिए वे डिवाइसों के बीच बना रहता है और उनके विज़ुअल आइकन बरकरार रहते हैं। यह उपयोगकर्ताओं को बड़े नोटबुक में टैग किए गए आइटम को प्रभावी ढंग से फ़िल्टर या खोजने की सुविधा भी देता है।

## पैकेज आयात करें
अपने जावा प्रोजेक्ट के लिए आवश्यक पैकेज आयात करके शुरू करें। अपने कोड में निम्नलिखित इम्पोर्ट्स शामिल करें:
```java
import java.awt.Color;
import java.io.IOException;
import com.aspose.note.Document;
import com.aspose.note.NoteTag;
import com.aspose.note.Outline;
import com.aspose.note.OutlineElement;
import com.aspose.note.Page;
import com.aspose.note.RichText;
import com.aspose.note.TagIcon;
import com.aspose.note.ParagraphStyle;
```

## चरण 1: दस्तावेज़ ऑब्जेक्ट बनाएं
`Document` शीर्ष‑स्तरीय क्लास है जो मेमोरी में OneNote फ़ाइल का प्रतिनिधित्व करता है। इंस्टैंसिएशन के बाद, सभी आगे की ऑपरेशन्स इस ऑब्जेक्ट के माध्यम से होते हैं।
```java
// The path to the documents directory.
String dataDir = "Your Document Directory";
// Create an object of the Document class
Document doc = new Document();
```

## चरण 2: पेज क्लास ऑब्जेक्ट इनिशियलाइज़ करें
`Page` OneNote नोटबुक के भीतर एकल पेज का प्रतिनिधित्व करता है। प्रत्येक पेज में कई आउटलाइन और अन्य तत्व हो सकते हैं।
```java
// Initialize Page class object
Page page = new Page();
```

## चरण 3: आउटलाइन क्लास ऑब्जेक्ट इनिशियलाइज़ करें
`Outline` पेज पर संबंधित तत्वों को समूहित करता है, जो एक या अधिक `OutlineElement` ऑब्जेक्ट्स के कंटेनर के रूप में कार्य करता है।
```java
// Initialize Outline class object
Outline outline = new Outline();
```

## चरण 4: outlineelement क्लास ऑब्जेक्ट इनिशियलाइज़ करें
`OutlineElement` सबसे छोटा विज़ुअल यूनिट है जो टेक्स्ट, इमेज या अन्य रिच कंटेंट को एक आउटलाइन के भीतर रख सकता है।
```java
// Initialize OutlineElement class object
OutlineElement outlineElem = new OutlineElement();
```

## चरण 5: टेक्स्ट स्टाइल कस्टमाइज़ करें
टेक्स्ट नोड के लिए स्टाइल सेट करें—यह वह जगह है जहाँ आप **पैराग्राफ स्टाइल** जैसे फ़ॉन्ट रंग, नाम और आकार सेट करते हैं। Aspose.Note आपको एक ही `RichTextStyle` ऑब्जेक्ट में RGB रंग, फ़ॉन्ट फ़ैमिली और पॉइंट साइज निर्दिष्ट करने की अनुमति देता है।
```java
// Customize text style
ParagraphStyle textStyle = new ParagraphStyle()
                                .setFontColor(Color.BLACK)
                                .setFontName("Arial")
                                .setFontSize(10);
```

## चरण 6: richtext ऑब्जेक्ट बनाएं
`RichText` वह क्लास है जो वास्तविक स्ट्रिंग कंटेंट रखता है। ऑब्जेक्ट बनाने के बाद, आप इच्छित टेक्स्ट जोड़ते हैं, जिसे बाद में टैग मिलेगा।
```java
// Create RichText object
RichText text = new RichText().append("OneNote text.");
text.setParagraphStyle(textStyle);
```

## चरण 7: नोट टैग जोड़ें
`Tag` एक विज़ुअल मार्कर (जैसे पीला सितारा) का प्रतिनिधित्व करता है जिसे किसी भी `RichText` से जोड़ा जा सकता है। Aspose.Note 30 से अधिक बिल्ट‑इन टैग आइकन प्रदान करता है, और आवश्यकता पड़ने पर आप कस्टम आइकन भी परिभाषित कर सकते हैं।
```java
// Add note tag
NoteTag noteTag = NoteTag.createYellowStar();
text.getTags().add(noteTag);
```

## चरण 8: टेक्स्ट नोड जोड़ें
`RichText` (उसके टैग के साथ) को `OutlineElement` से संलग्न करें। यह चरण स्टाइल किए हुए, टैग वाले टेक्स्ट को आउटलाइन पदानुक्रम से बाइंड करता है।
```java
// Add text node
outlineElem.appendChildLast(text);
```

## चरण 9: आउटलाइन एलिमेंट को आउटलाइन में जोड़ें
`OutlineElement` को `Outline` कंटेनर के भीतर रखें ताकि वह पेज की विज़ुअल स्ट्रक्चर का हिस्सा बन जाए।
```java
// Add outline element node
outline.appendChildLast(outlineElem);
```

## चरण 10: आउटलाइन को पेज में जोड़ें
`Outline` को `Page` संरचना में डालें, जिससे पेज की कंटेंट ट्री पूरी हो जाती है।
```java
// Add outline node
page.appendChildLast(outline);
```

## चरण 11: पेज को दस्तावेज़ में जोड़ें
पूरी तरह निर्मित `Page` को `Document` ऑब्जेक्ट में जोड़ें, जिससे नोटबुक को सहेजने के लिए तैयार किया जा सके।
```java
// Add page node
doc.appendChildLast(page);
```

## चरण 12: OneNote दस्तावेज़ सहेजें
अंत में, **OneNote फ़ाइल** को डिस्क पर **save** करें। यह **OneNote दस्तावेज़ बनाने** की वर्कफ़्लो को पूरा करता है और एक मानक *.one* फ़ाइल उत्पन्न करता है जिसे किसी भी हालिया Microsoft OneNote संस्करण में खोला जा सकता है।
```java
// Save OneNote document
doc.save(dataDir + "AddTextNodeWithTag_out.one");
```

## सामान्य समस्याएँ और समाधान
- **सेव करने के बाद टैग नहीं दिख रहा** – सुनिश्चित करें कि आप `richText.getTags().add(tag)` को `RichText` को `OutlineElement` से जोड़ने से पहले कॉल कर रहे हैं।  
- **फ़ॉन्ट स्टाइल अनदेखा हो रहा है** – जांचें कि `RichTextStyle` को `RichText` इंस्टेंस पर लागू किया गया है या नहीं, इससे पहले कि आप इसे आउटलाइन में जोड़ें।  
- **बड़ी नोटबुक्स में OutOfMemoryError** – फ़ाइलों के 500 MB से बड़े होने पर स्ट्रीमिंग मोड सक्षम करने के लिए `Document.setLoadOptions(new LoadOptions(LoadFormat.ONE))` का उपयोग करें।
