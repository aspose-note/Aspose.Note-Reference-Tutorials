# स्प्लिटिंग एल्गोरिदम के साथ onenote को pdf में निर्यात करें Aspose.Note

## परिचय

यदि आपको प्रोग्रामेटिक रूप से **export onenote to pdf** करना है, तो Aspose.Note for Java इसे सरल बनाता है। इस ट्यूटोरियल में हम Splitting Algorithm Method को देखेंगे, जो आपको कंटेंट को पेजों में कैसे विभाजित किया जाए, इस पर नियंत्रण देता है, जिससे एक साफ़ और पठनीय PDF आउटपुट सुनिश्चित होता है। आप देखेंगे कि PDF सेव विकल्प कैसे सेट करें, सही पेज‑स्प्लिटिंग एल्गोरिदम कैसे चुनें, और अंत में PDF फ़ाइल कैसे जेनरेट करें—सिर्फ कुछ ही Java कोड लाइनों से।

## त्वरित उत्तर

- **स्प्लिटिंग एल्गोरिदम क्या करता है?** यह निर्धारित करता है कि पेज सीमाओं को पार करने वाले ऑब्जेक्ट्स को OneNote पेजों को PDF में निर्यात करते समय कैसे संभाला जाता है।  
- **कौनसी लाइब्रेरी आवश्यक है?** Aspose.Note for Java (आधिकारिक Aspose साइट से डाउनलोड करें)।  
- **क्या मुझे लाइसेंस चाहिए?** प्रोडक्शन उपयोग के लिए एक अस्थायी या पूर्ण लाइसेंस आवश्यक है; एक मुफ्त ट्रायल उपलब्ध है।  
- **क्या मैं बड़े OneNote नोटबुक्स निर्यात कर सकता हूँ?** हाँ – लाइब्रेरी हजारों पेजों वाले नोटबुक्स को कुशलतापूर्वक प्रोसेस करती है और आपको पेज‑स्प्लिटिंग नियम सेट करने देती है।  
- **कौनसे आउटपुट फ़ॉर्मेट समर्थित हैं?** PDF, JPEG, PNG, XPS, और अधिक; यह गाइड PDF निर्यात पर केंद्रित है।  
- **मैं PDF इमेजेज़ को कैसे संपीड़ित कर सकता हूँ?** `pdfSaveOptions.setCompressImages(true)` का उपयोग करके जेनरेटेड PDF में इमेज का आकार कम करें।  

## export onenote to pdf क्या है?

Exporting onenote to pdf का मतलब है मूल `.one` फ़ाइल फ़ॉर्मेट को एक पोर्टेबल PDF दस्तावेज़ में बदलना। यह रूपांतरण मूल लेआउट, टेक्स्ट फ़ॉर्मेटिंग, और एम्बेडेड ऑब्जेक्ट्स को संरक्षित करता है, जिससे सामग्री को साझा करना, संग्रहित करना, या प्रिंट करना आसान हो जाता है, बिना OneNote एप्लिकेशन की आवश्यकता के। परिणामी PDF को किसी भी डिवाइस पर खोला जा सकता है जो PDF व्यूइंग का समर्थन करता है।

## export onenote to pdf के लिए स्प्लिटिंग एल्गोरिदम का उपयोग क्यों करें?

स्प्लिटिंग एल्गोरिदम आपको टेबल, इमेज, और ड्रॉइंग जैसे जटिल ऑब्जेक्ट्स को पेज ब्रेक पर कैसे संभाला जाए, इस पर सूक्ष्म नियंत्रण देता है। उपयुक्त एल्गोरिदम चुनकर आप विज़ुअल लेआउट को संरक्षित कर सकते हैं, क्लिप्ड कंटेंट से बच सकते हैं, और जेनरेटेड पेजों की कुल संख्या को कम कर सकते हैं। इससे साफ़ PDFs, बेहतर पठनीयता, और अधिक कुशल स्टोरेज मिलता है, विशेष रूप से कई मिश्रित‑मीडिया तत्वों वाले बड़े नोटबुक्स के लिए।

* प्रत्येक पेज के विज़ुअल लेआउट को संरक्षित रखें।  
* क्लिप्ड कंटेंट से बचें जो अन्यथा कट जाता।  
* जब ऑब्जेक्ट्स को अगले पेज पर साफ़-साफ़ ले जाया जा सकता है, तो जेनरेटेड पेजों की संख्या कम करें।  

## .one फ़ाइल को pdf में कैसे बदलें?

एक `.one` फ़ाइल को PDF में बदलने के लिए, पहले स्रोत OneNote दस्तावेज़ को मेमोरी में लोड करें, फिर इच्छित स्प्लिटिंग एल्गोरिदम और इमेज कॉम्प्रेशन जैसी अतिरिक्त सेटिंग्स के साथ `PdfSaveOptions` को कॉन्फ़िगर करें। अंत में, `Document` ऑब्जेक्ट पर `save` मेथड को कॉल करें, आउटपुट PDF पाथ निर्दिष्ट करते हुए। यह तीन‑स्टेप पैटर्न किसी भी आकार के नोटबुक्स के लिए काम करता है और पेज‑ब्रेक हैंडलिंग को निर्धारक बनाता है।

## पैकेज आयात करें

अपने Java प्रोजेक्ट में, Aspose.Note कार्यक्षमताओं का उपयोग करने के लिए आवश्यक पैकेज आयात करें।

```java
import java.io.IOException;
import com.aspose.note.AlwaysSplitObjectsAlgorithm;
import com.aspose.note.Document;
import com.aspose.note.KeepPartAndCloneSolidObjectToNextPageAlgorithm;
import com.aspose.note.KeepSolidObjectsAlgorithm;
import com.aspose.note.PdfSaveOptions;
```

## चरण 1: दस्तावेज़ डायरेक्टरी निर्धारित करें

उस डायरेक्टरी को सेट करें जहाँ आपका OneNote दस्तावेज़ स्थित है।

```java
String dataDir = "Your Document Directory";
```

## चरण 2: OneNote दस्तावेज़ लोड करें

`Document` क्लास मेमोरी में OneNote नोटबुक का प्रतिनिधित्व करती है, जिससे आप उसके पेज पढ़, संशोधित, और सहेज सकते हैं।

```java
Document doc = new Document(dataDir + "Sample1.one");
```

## चरण 3: PDF सेव विकल्प सेट करें

`PdfSaveOptions` क्लास PDF निर्यात सेटिंग्स को परिभाषित करती है जैसे पेज स्प्लिटिंग, इमेज कॉम्प्रेशन, और अनुपालन स्तर।

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
```

## चरण 4: पेज स्प्लिटिंग एल्गोरिदम सेट करें

`KeepPartAndCloneSolidObjectToNextPageAlgorithm` एल्गोरिदम ऑब्जेक्ट का एक भाग वर्तमान पेज पर रखता है और शेष भाग को अगले पेज पर क्लोन करता है, लेआउट को संरक्षित रखते हुए।

```java
pdfSaveOptions.setPageSplittingAlgorithm(new KeepPartAndCloneSolidObjectToNextPageAlgorithm(100));
```

## चरण 5: दस्तावेज़ सहेजें

निर्दिष्ट PDF सेव विकल्पों के साथ दस्तावेज़ सहेजें। यह चरण **PDF onenote** आउटपुट जेनरेट करता है जिसे आप खोल सकते हैं, साझा कर सकते हैं, या प्रिंट कर सकते हैं।

```java
try {
    doc.save(dataDir + "UsingSplittingAlgorithmMethod_out.Jpeg", pdfSaveOptions);
} catch (Exception ex) {
    System.out.println("Exception: " + ex.getMessage());
}
```
