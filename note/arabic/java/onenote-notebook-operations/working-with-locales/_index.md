# كيفية تعيين اللغة في OneNote – Aspose.Note Java

## المقدمة

إذا كنت بحاجة إلى **كيفية تعيين اللغة** أثناء معالجة ملفات OneNote، فإن Aspose.Note for Java يجعل ذلك بسيطًا. في هذا الدرس سنستعرض كل ما تحتاجه — من تثبيت ترخيص Aspose، تحميل مستند OneNote، تغيير اللغة، إلى تحويل الملف إلى صورة PNG. في النهاية، ستكون قادرًا على تخصيص إعدادات اللغة وإنشاء مخرجات مخصصة للغة باستخدام بضع أسطر فقط من كود Java، وهو أمر أساسي للتطبيقات متعددة الجنسيات.

## إجابات سريعة
- **ماذا يفعل “set default locale”?** يحدد اللغة وتنسيق المنطقة المستخدمة من قبل Aspose.Note عند قراءة أو كتابة ملفات OneNote.  
- **هل أحتاج إلى ترخيص؟** نعم — قم بتعيين ترخيص Aspose لفتح جميع الوظائف.  
- **ما نسخة Java المطلوبة؟** أي JDK 8+ مدعومة.  
- **هل يمكنني تحويل OneNote إلى PNG؟** بالتأكيد؛ تسمح لك الـ API بحفظ الصفحات كصور.  
- **هل العملية آمنة للخطوط المتعددة؟** تعيين اللغة الافتراضية هو إعداد عالمي، لذا قم بتكوينه مرة واحدة عند بدء تشغيل التطبيق.

## ما هو “set default locale” في Aspose.Note؟

تعيين اللغة الافتراضية يخبر Aspose.Note أي لغة وعادات ثقافية يجب تطبيقها عند تحليل التواريخ والأرقام والنصوص. يجيب هذا الشرح مباشرة على سؤال “ما هو” في 45 كلمة، مما يضمن قدرة الذكاء الاصطناعي على استخراج تعريف مختصر. وهو أمر أساسي للتطبيقات متعددة المناطق التي تحتاج إلى تنسيق موحد عبر لغات المستخدمين المختلفة.

## لماذا يتم تعيين اللغة الافتراضية عند العمل مع OneNote؟

تعيين اللغة الافتراضية يضمن أن التواريخ والأرقام والسلاسل المستخرجة تتبع عادات المنطقة المستهدفة، مما يمنع سوء تفسير البيانات ويضمن أن العناصر البصرية مثل التقويمات تُعرض بشكل صحيح. يؤدي ذلك إلى تمثيل دقيق للبيانات، سلاسل واجهة مستخدم متسقة، ونتائج تحويل صور أكثر سلاسة.

## المتطلبات المسبقة

- **بيئة تطوير Java:** JDK 8 أو أحدث مثبت ومُعَّد `JAVA_HOME`.  
- **مكتبة Aspose.Note:** قم بتنزيل أحدث JAR من [رابط التحميل](https://releases.aspose.com/note/java/).  
- **ملف ترخيص Aspose صالح** (الإصدار التجريبي المجاني يعمل للاختبار).

## استيراد الحزم

تمثل الفئة `Locale` منطقة جغرافية أو سياسية أو ثقافية محددة.  
```java
import java.io.IOException;
import java.nio.file.Path;
import java.util.Locale;
import com.aspose.note.Document;
import com.aspose.note.License;
import com.aspose.note.LocaleOptions;
```

## الخطوة 1: تعيين ترخيص Aspose

تقوم الفئة `License` بتحميل ملف الترخيص الذي اشتريته وتفتح جميع الميزات المتقدمة، بما في ذلك معالجة اللغة وتحويل الصور.  
```java
License license = new License();
license.setLicense("licenseFile");
```

## الخطوة 2: تعيين اللغة الافتراضية

`Locale` هي أداة في Java تُغلف رموز اللغة والبلد.  
هنا نقوم بتعيين اللغة الافتراضية إلى الإنجليزية (`en`) مع رمز البلد `RS`. عدّل رموز اللغة والبلد لتتناسب مع المنطقة المستهدفة قبل أي عمليات على المستند.  
```java
java.util.Locale.setDefault(new java.util.Locale("en", "rs"));
```

## الخطوة 3: تحميل مستند OneNote

`Document` هو الكائن الأعلى مستوى في Aspose.Note والذي يمثل ملف OneNote واحد في الذاكرة. بعد إنشاءه، جميع عمليات القراءة والكتابة تمر عبر هذا الكائن.  
```java
String inputFile = "Sample1.one";
Path inputPath = Paths.get(inputFile);

Document oneFile = new Document(inputPath.toString());
```

## الخطوة 4: تحويل OneNote إلى PNG (تحويل ملف OneNote)

يمكن لكائنات `Page` داخل `Document` أن تُرسم كصور نقطية. تقوم طريقة `save` بتنفيذ تحويل ملف OneNote، وتصدير الدفتر (أو صفحة محددة) كصورة PNG — بفعالية **convert onenote to png** و **save onenote as image**.  
```java
oneFile.save("sample.png");
```

## المشكلات الشائعة والنصائح
- **الترخيص غير موجود:** تأكد من أن مسار `licenseFile` صحيح وأن الملف لديه صلاحيات القراءة.  
- **اللغة غير مطبقة:** استدعِ `Locale.setDefault` **قبل** تحميل المستند؛ وإلا سيتجاهل الإعداد الافتراضي للغة.  
- **عدم وجود مخرجات صورة:** تحقق من أن ملف OneNote يحتوي فعليًا على صفحات قابلة للعرض؛ الدفاتر الفارغة ستنتج صورة PNG فارغة.  
- **نصيحة الأداء:** يمكن لـ Aspose.Note for Java معالجة دفاتر تصل إلى 500 صفحة دون تحميل الملف بالكامل إلى الذاكرة، بفضل بنية البث الخاصة به (ادعاء مُقَدَّر).
