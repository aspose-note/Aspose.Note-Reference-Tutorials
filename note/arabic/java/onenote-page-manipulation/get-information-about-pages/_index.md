## استيراد الحزم

أولاً، استورد الفئات التي ستحتاجها. كتلة الاستيراد تبقى كما هي من الدليل الأصلي.

```java
import java.io.IOException;
import java.util.List;

import com.aspose.note.Document;
import com.aspose.note.LoadOptions;
import com.aspose.note.Page;
```

## الخطوة 1: تحميل مستند OneNote

`Document` هو الفئة الأساسية في Aspose.Note التي تمثل دفتر ملاحظات OneNote محملاً في الذاكرة، وتوفر الوصول إلى أقسامه وصفحاته.

حمّل ملف OneNote الخاص بك في كائن `Aspose.Note` من نوع `Document`.

```java
String dataDir = "Your Document Directory";
// Load the document into Aspose.Note
LoadOptions options = new LoadOptions();
Document doc = new Document(dataDir + "Sample1.one", options);
```

## كيف تسترجع aspose note page details برمجيًا؟

حمّل المستند، ثم قم بالتكرار عبر مجموعة الصفحات الخاصة به. **`Page`** يمثل صفحة فردية داخل مستند OneNote، يحتوي على محتواه وبياناته الوصفية. لكل كائن `Page` يمكنك قراءة `getLastModifiedTime()`، `getCreationTime()`، `getTitle()`، `getLevel()`، و `getAuthor()`. هذه الحلقة البسيطة تُعيد جميع تفاصيل aspose note page التي تحتاجها في بضع أسطر من الشيفرة.

## الخطوة 2: استرجاع معلومات الصفحة

الآن سنقوم **باستخراج last modified time** إلى جانب بيانات وصفية أخرى مفيدة.

```java
// Get page revisions
List<Page> pages = doc.getChildNodes(Page.class);

// Traverse list of pages
for (Page pageRevision : pages) {
    System.out.println("LastModifiedTime: " + pageRevision.getLastModifiedTime());
    System.out.println("CreationTime: " + pageRevision.getCreationTime());
    System.out.println("Title: " + pageRevision.getTitle());
    System.out.println("Level: " + pageRevision.getLevel());
    System.out.println("Author: " + pageRevision.getAuthor());
}
```

تطبع الحلقة **last modified time** لكل صفحة، ووقت الإنشاء، والعنوان، والمستوى الهرمي، والمؤلف إلى وحدة التحكم.

## مشكلات شائعة ونصائح

- **Null values** – قد لا تحتوي بعض الصفحات على مؤلف محدد؛ احرص على التعامل مع `null` أثناء المعالجة.  
- **Time zones** – `getLastModifiedTime()` تُعيد كائن `java.util.Date` في المنطقة الزمنية الافتراضية للنظام. حوّل إلى UTC إذا كنت تحتاج إلى مرجع عالمي.  
- **Large notebooks** – بالنسبة للدفاتر التي تحتوي على مئات الصفحات، فكر في المعالجة على دفعات لتقليل استهلاك الذاكرة.
