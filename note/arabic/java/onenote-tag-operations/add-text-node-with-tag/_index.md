# كيفية إضافة علامة إلى مستند OneNote عن طريق إضافة عقدة نصية باستخدام Aspose.Note

## مقدمة
في هذا الدرس ستتعلم **كيفية إضافة علامة** إلى مستند OneNote باستخدام Aspose.Note Java API. سنستعرض إنشاء ملف OneNote جديد، تنسيق فقرة، إرفاق علامة مدمجة بالنص، وأخيرًا حفظ الدفتر بند واحد `save`. سواء كنت تبني أداة لتدوين الملاحظات الشخصية أو تقوم بأتمتة تقارير المؤسسات، فإن الخطوات أدناه تمنحك تحكمًا برمجيًا كاملاً في محتوى OneNote.

## إجابات سريعة
- **ماذا يفعل Aspose.Note؟** يوفر API جافا لقراءة وتعديل وإنشاء ملفات OneNote دون الحاجة إلى تثبيت Microsoft Office.  
- **كم عدد أسطر الكود لإضافة عقدة نصية مع علامة؟** تقريبًا 15 سطرًا، تشمل إنشاء الكائنات وتنسيقها.  
- **هل أحتاج إلى ترخيص لتشغيل العينة؟** النسخة التجريبية المجانية تكفي للتطوير؛ الترخيص مطلوب للاستخدام في الإنتاج.  
- **هل يمكنني تغيير أيقونة العلامة؟** نعم – يقدم Aspose.Note أكثر من 30 أيقونة مدمجة مثل النجمة الصفراء، علامة الاختيار، والقلب.  
- **ما هو تنسيق ملف الإخراج؟** المكتبة تحفظ النتيجة كملف *.one* قياسي من نوع OneNote.

## ماذا يعني “إنشاء مستند OneNote”؟
إنشاء مستند OneNote يعني توليد ملف *.one* برمجيًا يمكن فتحه في Microsoft OneNote. يحتوي الملف على صفحات، مخططات، وعناصر نصية غنية تُبنى عبر Aspose.Note API، مما يتيح لك بناء دفاتر دون الحاجة إلى تطبيق سطح المكتب أو غيره.

## لماذا إضافة عقدة نصية مع علامة؟
إضافة علامة إلى عقدة نصية تبرز المعلومات المهمة وتُمكّن من التنقل عبر العلامات المدمجة في OneNote، مما يسرّع عملية المراجعة وإدارة المهام. تُخزن العلامات كبيانات وصفية، لذا تبقى موجودة عبر الأجهزة وتحتفظ بأيقوناتها البصرية. كما يتيح ذلك للمستخدمين تصفية أو البحث عن العناصر الموسومة بفعالية داخل دفاتر كبيرة.

## المتطلبات المسبقة
قبل الغوص في الدرس، تأكد من توفر المتطلبات التالية:
- معرفة أساسية ببرمجة جافا.  
- مكتبة Aspose.Note for Java مثبتة. يمكنك تنزيل مكتبة Aspose.Note for Java من [download Aspose.Note for Java](https://releases.aspose.com/note/java/).  
- بيئة تطوير متكاملة (IDE) مُعدّة لتطوير جافا.

## استيراد الحزم
ابدأ باستيراد الحزم اللازمة لمشروع جافا الخاص بك. في الكود، أدرج الاستيرادات التالية:
```java
import java.awt.Color;
import java.io.IOException;
import com.aspose.note.Document;
import com.aspose.note.NoteTag;
import com.aspose.note.Outline;
import com.aspose.note.OutlineElement;
import com.aspose.note.Page;
import com.aspose.note.RichText;
import com.aspose.note.TagIcon;
import com.aspose.note.ParagraphStyle;
```

## الخطوة 1: إنشاء كائن المستند
`Document` هو الفئة العليا التي تمثل ملف OneNote في الذاكرة. بعد إنشاءه، تمر جميع العمليات اللاحقة عبر هذا الكائن.
```java
// The path to the documents directory.
String dataDir = "Your Document Directory";
// Create an object of the Document class
Document doc = new Document();
```

## الخطوة 2: تهيئة كائن فئة الصفحة
`Page` تمثل صفحة واحدة داخل دفتر OneNote. يمكن لكل صفحة احتواء مخططات وعناصر أخرى متعددة.
```java
// Initialize Page class object
Page page = new Page();
```

## الخطوة 3: تهيئة كائن فئة المخطط
`Outline` يجمع العناصر المرتبطة على الصفحة، ويعمل كحاوية لواحد أو أكثر من كائنات `OutlineElement`.
```java
// Initialize Outline class object
Outline outline = new Outline();
```

## الخطوة 4: تهيئة كائن فئة عنصر المخطط
`OutlineElement` هو أصغر وحدة بصرية يمكنها احتواء نص أو صور أو محتوى غني آخر داخل المخطط.
```java
// Initialize OutlineElement class object
OutlineElement outlineElem = new OutlineElement();
```

## الخطوة 5: تخصيص نمط النص
قم بإعداد نمط عقدة النص—هنا تقوم **بتعيين نمط الفقرة** مثل لون الخط، الاسم، والحجم. يتيح Aspose.Note تحديد ألوان RGB، عائلات الخطوط، وحجم النقاط في كائن `RichTextStyle` واحد.
```java
// Customize text style
ParagraphStyle textStyle = new ParagraphStyle()
                                .setFontColor(Color.BLACK)
                                .setFontName("Arial")
                                .setFontSize(10);
```

## الخطوة 6: إنشاء كائن RichText
`RichText` هو الفئة التي تحتفظ بالمحتوى النصي الفعلي. بعد إنشاء الكائن، تُضيف النص المطلوب، والذي سيُرفق لاحقًا بالعلامة.
```java
// Create RichText object
RichText text = new RichText().append("OneNote text.");
text.setParagraphStyle(textStyle);
```

## الخطوة 7: إضافة علامة ملاحظة
`Tag` تمثل علامة بصرية (مثل النجمة الصفراء) يمكن إرفاقها بأي `RichText`. يوفر Aspose.Note أكثر من 30 أيقونة علامة مدمجة، ويمكنك أيضًا تعريف أيقونات مخصصة إذا لزم الأمر.
```java
// Add note tag
NoteTag noteTag = NoteTag.createYellowStar();
text.getTags().add(noteTag);
```

## الخطوة 8: إضافة عقدة نصية
اربط `RichText` (مع علامتها) بـ `OutlineElement`. هذه الخطوة تربط النص المنسق والموسوم بهيكل المخطط.
```java
// Add text node
outlineElem.appendChildLast(text);
```

## الخطوة 9: إضافة عنصر المخطط إلى المخطط
ضع `OutlineElement` داخل حاوية `Outline` لتصبح جزءًا من البنية البصرية للصفحة.
```java
// Add outline element node
outline.appendChildLast(outlineElem);
```

## الخطوة 10: إضافة المخطط إلى الصفحة
أدرج `Outline` في بنية `Page`، مكملًا شجرة محتوى الصفحة.
```java
// Add outline node
page.appendChildLast(outline);
```

## الخطوة 11: إضافة الصفحة إلى المستند
أضف `Page` المكتملة إلى كائن `Document`، مهيئًا الدفتر للحفظ.
```java
// Add page node
doc.appendChildLast(page);
```

## الخطوة 12: حفظ مستند OneNote
أخيرًا، **احفظ ملف OneNote** على القرص. هذا يُكمل سير عمل **إنشاء مستند OneNote** وينتج ملف *.one* قياسي يمكن فتحه في أي نسخة حديثة من Microsoft OneNote.
```java
// Save OneNote document
doc.save(dataDir + "AddTextNodeWithTag_out.one");
```

## لماذا هذا مهم
يدعم Aspose.Note **أكثر من 50 تنسيقًا للإدخال والإخراج** (بما في ذلك DOCX، PDF، HTML، وأنواع الصور) ويمكنه معالجة دفاتر مئات الصفحات دون تحميل الملف بالكامل إلى الذاكرة، مما يجعله مناسبًا للأتمتة على الخادم وتوليد ملاحظات على نطاق واسع.

## المشكلات الشائعة والحلول
- **العلامة لا تظهر بعد الحفظ** – تأكد من استدعاء `richText.getTags().add(tag)` قبل إرفاق `RichText` إلى `OutlineElement`.  
- **تُتجاهل تنسيقات الخط** – تحقق من تطبيق `RichTextStyle` على كائن `RichText` قبل إضافته إلى المخطط.  
- **دفاتر كبيرة تسبب OutOfMemoryError** – استخدم `Document.setLoadOptions(new LoadOptions(LoadFormat.ONE))` لتفعيل وضع البث للملفات التي يزيد حجمها عن 500 ميغابايت.
