# كيفية تحويل OneNote إلى PNG وحفظه كصورة بتدرج رمادي

## مقدمة

في هذا الدرس ستتعلم **كيفية تحويل OneNote إلى PNG** وتخزين النتيجة كصورة بتدرج رمادي باستخدام Aspose.Note for .NET. تحويل صفحات OneNote إلى PNG هو طلب شائع للتقارير، إنشاء الصور المصغرة، وتدفقات الأرشفة. تجعل Aspose.Note العملية بسيطة، حيث يمكنك التعامل مع الملفات دون الحاجة إلى تثبيت Microsoft OneNote.

## إجابات سريعة
- **ما المكتبة التي تتعامل مع التحويل؟** Aspose.Note for .NET.
- **ما الصيغة التي يتم إنتاجها؟** صورة PNG بتدرج رمادي.
- **كم عدد أسطر الكود المطلوبة؟** أربع عبارات أساسية (تحميل، ضبط الخيارات، حفظ، التحقق).
- **هل يلزم ترخيص للإنتاج؟** نعم، يلزم الحصول على ترخيص تجاري؛ يتوفر نسخة تجريبية مجانية.
- **هل يمكن تشغيله على .NET 6+؟** بالتأكيد – يدعم Aspose.Note .NET Framework 4.5+، .NET Core 3.1+، و .NET 6+.

## ما هو تحويل OneNote إلى PNG؟

`convert OneNote to PNG` هو عملية تحويل صفحة OneNote إلى صورة Portable Network Graphics (PNG) بتنسيق bitmap، مع إمكانية تطبيق تحويلات مساحة اللون مثل التدرج الرمادي. يحافظ هذا التنسيق على الدقة البصرية مع إنتاج صورة خفيفة الوزن وصديقة للويب. يُستخدم عادةً لتضمين لقطات المستندات في صفحات الويب، إنشاء صور مصغرة، أو أرشفة المحتوى بصيغة لا تعتمد على برامج مملوكة.

## لماذا نستخدم Aspose.Note لهذا التحويل؟

يدعم Aspose.Note **أكثر من 50 تنسيقًا** للإدخال والإخراج ويمكنه عرض دفاتر OneNote متعددة الصفحات دون تحميل الملف بالكامل في الذاكرة، مما يتيح تحويل مستندات تصل إلى **500 ميغابايت** في أقل من **2 ثانية** على خوادم عادية. كما توفر المكتبة إمكانية عرض التدرج الرمادي مدمجة، مما يلغي الحاجة إلى أدوات معالجة صور خارجية.

- مكتبة Aspose.Note for .NET مثبتة. يمكنك تنزيلها من **صفحة تنزيل Aspose.Note for .NET**[Aspose.Note for .NET download page](https://releases.aspose.com/note/net/).  
- الإلمام بالوصول إلى الملفات ومعالجتها باستخدام .NET.

## كيف يمكنني تحويل OneNote إلى PNG وحفظه كصورة بتدرج رمادي؟

حمّل مستند OneNote، اضبط خيارات حفظ الصورة لتمكين التدرج الرمادي، احفظ النتيجة كملف PNG، وأخيرًا تأكد من وجود الملف على القرص. يغطي سير العمل الكامل الخطوات الأربع أدناه. كل خطوة موضحة بمقتطفات كود مختصرة يمكن دمجها مباشرة في تطبيقك.

### استيراد مساحات الأسماء

لنبدأ باستيراد مساحات الأسماء الضرورية:

```csharp
using System;

using Aspose.Note.Saving;

```

### الخطوة 1: تحميل المستند

أولاً، قم بتحميل المستند إلى Aspose.Note.  
تمثل الفئة `Document` دفتر OneNote وتوفر طرقًا لتحميل محتوياته ومعالجتها.

```csharp
string dataDir = "Your Document Directory";
Document oneFile = new Document(dataDir + "Aspose.one");
```

### الخطوة 2: حفظ كصورة بتدرج رمادي

بعد ذلك، حدد المسار لحفظ الصورة بتدرج رمادي واحفظ المستند وفقًا لذلك.  
تتيح لك الفئة `ImageSaveOptions` تحديد تنسيق الصورة وخيارات العرض مثل وضع اللون.

```csharp
dataDir = dataDir + "SaveAsGrayscaleImage_out.png";
oneFile.Save(dataDir, new ImageSaveOptions(SaveFormat.Png)
					  {
						  ColorMode = ColorMode.GrayScale
					  });
```

### الخطوة 3: التحقق وعرض النتيجة

أخيرًا، تحقق من نجاح التحويل وعرض رسالة التأكيد مع مسار الملف.

```csharp
Console.WriteLine("\nOneNote document converted successfully to grayscale image.\nFile saved at " + dataDir);
```

## المشكلات الشائعة والحلول

- **الملف غير موجود بعد الحفظ** – تأكد من وجود دليل الإخراج وأن التطبيق يمتلك أذونات الكتابة.  
- **الصورة تظهر بالألوان** – تحقق من أن `ImageSaveOptions` تم ضبط `ColorMode` إلى `Grayscale`.  
- **الدفاتر الكبيرة تسبب استهلاك عالي للذاكرة** – استخدم `LoadOptions` مع `LoadOptions.LoadMode = LoadMode.Stream` لمعالجة الصفحات بشكل متسلسل.
